# Course Summarizer

A GPT plugin that turns course materials into structured, exam-ready study notes and knowledge outlines.

## Features

- **Structured review notes:** Organizes key concepts by topic and knowledge dependency, rather than simply copying slide order.
- **Course-aware summaries:** Preserves important terminology, formulas, notation, and course-specific explanations.
- **Clear comparisons:** Highlights distinctions between easily confused concepts.
- **Multilingual support:** Keeps technical terms in their original language when helpful.
- **Markdown output:** Produces concise study outlines, with quick-reference sections when useful.

## Installation

1. Open the [latest v1.0.0 release](https://github.com/harkerxia/gpt-course-summarizer/releases/tag/v1.0.0).
2. Under **Assets**, download the packaged plugin file (not the automatically generated source-code archive).
3. Drag and drop the downloaded plugin package into **ChatGPT**, then follow any installation prompts.
4. Once installed, the plugin will be available as **Summarizer**.

## Usage

Upload or provide your lecture notes, slides, course readings, or other study materials in ChatGPT. Then mention `@summarizer` to invoke the plugin.

For example:

```text
@summarizer Summarize these chapters into an exam-ready knowledge outline.
```

```text
@summarizer Turn these lecture notes into structured review notes.
```

```text
@summarizer Summarize this course material while preserving important exam terminology.
```

The plugin focuses on the supplied course materials and relevant conversation context. It aims to preserve core knowledge while keeping each entry concise and easy to review.
